================================================================================
                          TRUST FORMULA SUPPORT
================================================================================

The SDK correctly implements the trust formula:

  task_score = 0.40×WFS + 0.35×TSR + 0.15×RH + 0.10×SS

Where:
  • WFS = Weighted Feedback Score (40%)
  • TSR = Task Success Rate (35%)
  • RH = Reliability/History (15%)
  • SS = Specialization Score (10%)

The SDK's export_reputation() method returns all components:

  {
    "trust_score": 0.75,
    "components": {
      "feedback_score": 0.80,      # 40%
      "success_rate": 0.90,        # 35%
      "reliability": 0.65,         # 15%
      "specialization": 0.70       # 10%
    }
  }
